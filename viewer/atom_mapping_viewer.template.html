Supercell Atom Matching

Each small cell is matched atom by atom to its own 2× supercell using UMA or MACE-MH1 atom embeddings. The left view is the answer key: the small cell repeated twice and laid over the supercell. The right view paints every supercell atom with the colour and number of the small-cell atom it was matched to. When the matching is right, the two views look the same.

Rings mark mistakesA red ring is a supercell atom matched to the wrong site. An olive ring is a symmetry-equivalent copy of the right site, which no embedding can tell apart; it is shown only where the parent space group was recovered.
Bonds show the geometryGrey bonds join neighbours that were matched to neighbours. Red bonds were pulled apart by the matching. Plain OT ignores positions, so it breaks many bonds; FGW adds a penalty for that.
Data: 10 OMat24 sr_1m materials, each a rattled-relax cell and its rattled-300 supercell (volume per atom within 5%). Embeddings: UMA uma-s-1p2 (128) and MACE mace-mh-1 readout (96), z-scored per channel. UMA+MH1 concatenates both, each block scaled by 1/√width so the two models count equally. Plain OT: exact uniform optimal transport. FGW: fused Gromov–Wasserstein, α = , with the small cell tiled to supercell size; its geometry term is a Gaussian neighbour kernel summed over all periodic images (or, for comparison, the nearest image only). The rattling moves each atom about 0.6 Å, so even the true match breaks some bonds.
